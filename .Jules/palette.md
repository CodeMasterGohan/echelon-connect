# Palette's Journal - UX/Accessibility Learnings

## 2026-01-10 - Touch-Screen Tooltip Consideration

**Learning:** On touch-screen-only apps (tablets, phones), tooltips don't provide hover benefits but still serve important accessibility purposes:
- Screen readers (TalkBack/VoiceOver) read tooltip text
- Long-press reveals tooltip on mobile

**Action:** Still add tooltips to icon-only buttons for a11y compliance, but prioritize other UX improvements (loading states, confirmation dialogs) for more visible impact on touch-first apps.
